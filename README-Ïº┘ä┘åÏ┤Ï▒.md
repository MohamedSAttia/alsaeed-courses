# منصة السعيد لمحاكاة اختبار PMP® — نسخة Vercel

**إعداد وتصميم وبرمجة © د. محمد عطية — Al Saeed ETC — جميع الحقوق محفوظة**

**محرك اختبارات متعدد الدورات (Multi-Course Assessment Engine)** — الإصدار 3.0

منصة Core Engine قابلة للتوسع: كل شيء (الأسئلة، الاشتراكات، المدفوعات، النتائج، الإحصاءات) مرتبط بمعرّف الدورة `course_id` — تضيف دورة جديدة (RMP, ACP, GRCP, P3O, CPHM, Lean Six Sigma, Compliance...) من لوحة التحكم **دون أي تعديل برمجي**. تعمل على Vercel مجانًا مع قاعدة بيانات Neon Postgres.

## 🏗️ البنية المعمارية (المرحلة الثانية — منجزة)

```
Core Platform (Users • Payments • Enrollments • Admin)
      │
      ├── PMP Module   ✅ متاح (198 سؤالًا — ECO 2026 + PMBOK® 8)
      ├── RMP Module   🔜 مبذور في الكتالوج «قريبًا»
      ├── ACP Module   🔜
      ├── GRCP Module  🔜
      ├── P3O Module   🔜
      ├── CPHM Module  🔜
      ├── LSS Module   🔜
      └── أي دورة جديدة → تُضاف من تبويب «الدورات» في لوحة التحكم
```

**كل دورة تملك مستقلًا:** بنك أسئلة • فصولًا ديناميكية (JSON) • توقيتًا (ثانية/سؤال) • درجة اجتياز • سعرًا وعملة • حالة إتاحة (متاح/قريبًا) • لوحة إحصاءات (مشتركون، محاولات، متوسط النتائج).

**تدفق الاشتراك لكل دورة:** المتدرب يسجّل مرة واحدة → يطلب الاشتراك في دورة → يبلغ بالسداد (مرتبط بالدورة) → اعتماد الدفعة يفعّل **تلك الدورة فقط** تلقائيًا. البريد المسموح يدعم التفعيل المسبق لدورة محددة أو لكل الدورات المتاحة.

**رابط المحاكاة لكل دورة:** `‎/exam.html?course=pmp` (أو rmp، acp...) — نفس المحرك يقرأ فصول الدورة وتوقيتها ودرجة اجتيازها ديناميكيًا.

## 🚀 خطوات النشر (10 دقائق — مرة واحدة)

### 1) ارفع المشروع إلى GitHub
1. أنشئ مستودعًا جديدًا (Private) على github.com — مثلًا `al-saeed-pmp`.
2. من داخل مجلد المشروع على جهازك:
```bash
git init
git add .
git commit -m "منصة السعيد PMP — الإصدار الأول"
git branch -M main
git remote add origin https://github.com/USERNAME/al-saeed-pmp.git
git push -u origin main
```

### 2) استورد المشروع في Vercel
1. ادخل إلى **vercel.com** وسجّل بحساب GitHub.
2. **Add New → Project** ثم اختر مستودع `al-saeed-pmp`.
3. في خانة **Framework Preset** اختر **Other** (لا يوجد Build — اترك الإعدادات كما هي).
4. لا تضغط Deploy بعد — أضف قاعدة البيانات أولًا (الخطوة 3).

### 3) أضف قاعدة بيانات Neon Postgres (مجانية)
1. من صفحة المشروع في Vercel: تبويب **Storage → Create Database → Neon (Postgres)**.
2. اختر أقرب منطقة (مثل Frankfurt) واضغط **Create & Connect**.
3. سيضيف Vercel تلقائيًا متغير `DATABASE_URL` للمشروع. ✅

### 4) أضف متغيرات البيئة
من **Settings → Environment Variables** أضف:

| المتغير | القيمة | ملاحظة |
|---|---|---|
| `AUTH_SECRET` | نص عشوائي طويل (40+ حرفًا) | **إلزامي** — مفتاح توقيع الجلسات |
| `ADMIN_EMAIL` | بريدك الإداري | اختياري — الافتراضي `admin@al-ltc.com` |
| `ADMIN_PASSWORD` | كلمة مرور قوية | اختياري — الافتراضي `Saeed@2026` |

> لتوليد `AUTH_SECRET` عشوائي: `openssl rand -hex 32`

### 5) انشر
اضغط **Deploy**. عند أول زيارة للموقع ستُنشأ الجداول ويُزرع بنك الأسئلة (198 سؤالًا) وحساب المدير تلقائيًا.

> ⚠️ **مهم:** ادخل فورًا إلى `/admin.html` وغيّر كلمة مرور المدير من تبويب الإعدادات إن كنت استخدمت القيمة الافتراضية.

## 👨‍💼 سير العمل اليومي (كمدير)

### إضافة متدربين سدّدوا الرسوم (الطريقة الأسرع)
لوحة التحكم → تبويب **✉️ البريد المسموح** → الصق بريد المتدربين (عدة عناوين دفعة واحدة) → **إضافة**.
- عندما يسجّل المتدرب بهذا البريد يُفعَّل حسابه **تلقائيًا** ويدخل المحاكاة فورًا.
- إن كان مسجَّلًا من قبل بحالة «بانتظار التفعيل» فسيُفعَّل لحظة إضافة بريده.

### اعتماد المدفوعات الواردة
المتدرب يسجّل → يرى الرسوم وتعليمات الدفع في لوحته → يحوّل ويُدخل رقم المرجع → يظهر لديك في تبويب **💳 المدفوعات** → زر **✅ اعتماد وتفعيل** يفعّل حسابه فورًا.

### إدارة المستخدمين
تبويب **👥 المستخدمون**: تفعيل/إيقاف/حظر، إعادة تعيين كلمة مرور 🔑، حذف، أو إنشاء حساب يدويًا بكلمة مرور مولَّدة.

### ضبط الرسوم والدفع
تبويب **⚙️ الإعدادات**: قيمة الرسوم والعملة، تعليمات التحويل البنكي (آيبان)، رابط الدفع الإلكتروني على al-ltc.com، رقم الواتساب، و«الوضع المجاني المفتوح» للعروض المؤقتة.
